# Experiments

Individual experiment directories.

## Registry

See [registry.yaml](registry.yaml) for the canonical ID-to-directory mapping.

## Naming

Directory: `YYYY-MM-DD-{identifier}`
ID: `EXP-NNN-SLUG` (assigned sequentially; slug is a human-readable hint, not a unique key)

## Structure

See `templates/` for directory templates. Each experiment directory contains a `meta.yaml` with its assigned ID.
